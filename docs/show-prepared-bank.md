Банк готовых вопросов для 3D-шоу
================================

Режим «Играть с ботами» использует только шесть опубликованных курсов подготовленного банка: информатика (36 вопросов), математика, физика, биология, география и литература (по 10 вопросов). Все 86 заданий доступны с первого уровня без требования XP. Старые демонстрационные курсы C#, SQL и Web доступны в обычном обучении, но не попадают в каталог игры с ботами.

Вопросы, варианты, объяснения и элементы последовательностей/соответствий подготовлены на русском, казахском и английском языках. Язык приходит как `language: "ru" | "kk" | "en"` в теле запросов игры либо как параметр запросов каталога/состояния. Переключение языка меняет представление; ID вариантов, таймер и результат ответа сохраняются. Сервер переводит текстовые ответы последовательностей/соответствий в исходное представление перед проверкой. Ключи, объяснения и подсказки отсутствуют в публичном содержимом вопроса до соответствующего этапа игры.

Перед каждым вопросом телевизор показывает текст 3 секунды, затем камера плавно возвращается к игрокам за 2 секунды. Сервер назначает `startedAt` после этих 5 секунд; срок ответа отсчитывается от `startedAt`, поэтому показ и движение камеры не отнимают время на ответ.

Частный `/multiplayer/questions` возвращает `questions[].translations` с тремя языками, заголовком, вопросом и вариантами с одинаковыми ID. `courseTitles` содержит три названия курса. Эти подготовленные переводы не требуют вызова ИИ.

Литературный курс «Кемел Тоқаев: Түнде атылған оқ» содержит оригинальные короткие вопросы об авторе, форме повести, детективном жанре и проверенном кратком описании. Текст книги не воспроизводится, имена непроверенных героев и подробности сюжета не добавляются. Название, автор и краткая аннотация проверены по [Әдебиет порталы / QazContent](https://adebiportal.kz/ru/100kitap/kemel-toqaev-tunde-atylgan-oq); сведения о литературной и журналистской деятельности — по [библиотеке КазНУ](https://elibrary.kaznu.kz/kk/node/15266); форма повести и другое произведение автора подтверждены [издательством «Дарын»](https://darynbaspa.kz/kz/eshop/to-aev-kemel-sh-156-401-b).

Обновить только этот банк, сохранив пользователей, XP, попытки и другие курсы:

```powershell
cd PrismaService
npm run seed:show
```

Команда выполняет идемпотентные upsert с постоянными ID. Не запускайте полный seed для обновления только игровых вопросов. Проверки банка и локализации: `npm run test:show-bank`.

Интеграционная проверка работающего сервиса данных: из корня проекта `node scripts/verify-prepared-show.mjs`. Она проверяет каталог и три языка, пятисекундный показ, полный срок ответа, запрет раннего ответа и неизменность ID/таймера при смене языка. Проверка использует отдельную учётную запись без начисления XP и завершает свою сессию; отчёт сохраняется в `artifacts/prepared-show-report.json`.
